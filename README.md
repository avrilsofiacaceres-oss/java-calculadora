# Calculadora en Java
Calculadora de consola desarrollada como primer proyecto de mi portfolio de programación.
## Objetivo del proyecto
Practicar los fundamentos de Java mediante un programa que solicita dos numeros, realiza una suma y muestra el resultado en patalla.
## Funcionalidades
- Muestra un menú con las operaciones disponibles.
- Permite sumar, restar, multiplicar y dividir.
- Solicita al usuario dos números enteros.
- Muestra el resultado de la operación elegida.
- Valida que la opción ingresada sea correcta.
- Controla que no se intente dividir por cero.
- Muestra resultados decimales cuando es necesario.
## Tecnologias utilizadas
- Java 25
- IntelliJ IDEA
- Git
- GitHub
## Conceptos practicados
- Variables de tipo `int`
- Entrada de datos con `Scanner`
- Operador de suma
- Salida de datos por consola
- Declaración y asignación de variables
- Estructura de decisión `switch`
- Condicionales `if` y `else`
- Operador lógico OR `||`
- Finalización anticipada con `return`
- Números decimales con `double`
- Conversión de tipos mediante casting
- Validación de datos
